# Coddy companion plan

Coddy is a **practice companion**, not a replacement for this repository or the daily 90-day curriculum.

## Why it is included

The 90 Days of AI journey is project-led and GitHub remains the source of truth for progress. Coddy adds short browser-based exercises, instant feedback, AI hints, and focused practice in skills that support the roadmap: Python, Git, Terminal, SQL, Docker, and AI prompting.

## Rules

1. The GitHub day number and lesson objective always come first.
2. Use Coddy for **10–20 minutes after the main lesson**, not before it.
3. Choose only exercises that reinforce the current lesson. Do not jump ahead because Coddy unlocks another topic.
4. Write the important exercise again yourself in the day's notebook or project. A Coddy completion alone does not count as completing a 90 Days of AI day.
5. Use AI hints only after making your own attempt.
6. GitHub `STATE.json` remains the official progress record.

## Recommended sequence

- **Days 1–14:** Python fundamentals practice.
- **Days 15–30:** Python plus Git/Terminal and prompt-engineering practice when those topics appear in the curriculum.
- **Month 2:** Add SQL and relevant developer exercises alongside APIs, RAG and app work.
- **Month 3:** Add Docker/Terminal practice where it supports agents and automated pipelines.

## Daily companion block

At the end of each lesson:

- 10–20 min: one matching Coddy lesson/challenge.
- 5 min: explain what the code does without AI help.
- 5 min: reproduce or adapt the idea in the day's GitHub/Colab work.
- Record the Coddy topic in the day's learning notes.
