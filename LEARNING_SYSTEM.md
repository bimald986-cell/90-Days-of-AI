# Learning System

## What this repository is
This is a portable, AI-assisted learning system for learning AI step by step. The original "AI Learning Journey" is the first foundation track. The repository is designed to remain useful after the foundation track.

## Simplest way to use it
With an AI that can access this GitHub repository, say:

**Teach me today's AI lesson using my AI Learning Journey repository.**

If the AI cannot access GitHub, give it `AGENT_SYSTEM_PROMPT.md`, `STATE.json`, and `CURRICULUM.json`.

## Session rhythm
A lesson is not complete just because you read it. Each session should include recall, explanation, practice, an independent attempt, feedback, and a mastery check.

The default session is 60–120 minutes. Short sessions are allowed. Longer 3-hour project sessions are useful when appropriate. Progress follows mastery more than the calendar.

## Repository roles
- `AGENT_SYSTEM_PROMPT.md` — tells any AI how to teach.
- `CURRICULUM.json` — learning map and ongoing tracks.
- `STATE.json` — current progress and mastery.
- lesson notebooks/projects — evidence of actual work.
- README — public explanation of the journey.

## Rules
1. Never commit secrets or API keys.
2. Prefer official/current documentation for changing APIs.
3. Keep completed work; do not rewrite learning history.
4. If a prerequisite is weak, review it before advancing.
5. Projects should become progressively less copy-and-paste.
6. Learn multiple providers and open-source concepts so knowledge remains portable.
7. After the foundation track, select the next track based on goals and demonstrated gaps.

## Public repository
Public viewers can read/fork public content, but they cannot push changes to this repository unless the owner explicitly grants them write access. Do not add unknown collaborators. Contributions, if ever enabled, should go through owner-reviewed pull requests.


## Daily experience
Every day's mentor response should tell you exactly:
1. what you are learning,
2. why it matters,
3. the direct place/link and exact section to learn it,
4. where to practice it,
5. what to build/save,
6. how completion will be checked.

Choose **Quick (25–35 min)**, **Standard (60–90 min)** or **Deep (120–180 min)** without losing your place in the curriculum.

See `DAILY_RESOURCES.md` for trusted learning locations and `PROGRESS_SYSTEM.md` for tracking, weekly reviews and anti-boredom rules.
